# Бункер: После сирены

Пересобранная версия браузерной survival-игры.

## Что изменено

- Удалена старая фаза ручного сбора ресурсов за 60 секунд.
- Предметы теперь появляются случайно через ежедневные находки, тайники, решения и последствия событий.
- Добавлен карточный цикл выживания: каждый день расход пайков, состояние бункера, случайная находка и новое событие.
- Добавлены состояния бункера: корпус, энергия, воздух, сигнал, дух команды.
- Добавлены персонажи с ролями и влиянием на шанс событий: фельдшер, инженер, разведчица, связист.
- Добавлены SVG-иллюстрации бункера, персонажей и предметов.
- Реализованы сохранения в localStorage.
- Адаптивный интерфейс под телефон и Telegram WebApp.

## Запуск

Откройте `index.html` в браузере или загрузите папку на GitHub Pages/Vercel/любой статический хостинг.
